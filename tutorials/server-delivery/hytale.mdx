Use this tutorial after you [connect a server](/tutorials/server-delivery/connect-server) with the `PLUGIN` method.

## Before you begin

Make sure you have:

- Java 25.
- Hytale Server release API `0.6.8`.
- A Gamecart server configured as `PLUGIN`.
- The Gamecart Hytale executor JAR.

Download the current stable plugin: [gamecart-hytale.jar](https://cdn.gamecart.gg/executors/hytale/latest/gamecart-hytale.jar).

## Install and configure the executor

1. Copy the JAR into your Hytale server's `mods/` directory.
2. Start the server once to generate `mods/Gamecart_Gamecart/config.properties`.
3. Open `mods/Gamecart_Gamecart/config.properties` and set your server token.
4. Restart the server, or run `gamecart reload` after saving a valid configuration.

```properties
serverToken=
apiUrl=https://api.gamecart.gg
pollIntervalSeconds=15
debug=false
```

Copy the server token from **Integrations > Servers**. Keep it secret.

Set `pollIntervalSeconds` to a value from `5` through `600`. Unless you are testing on loopback, `apiUrl` must use HTTPS. With `debug=true`, the executor logs sanitized state and status information. It does not log tokens, commands, player identifiers, HTTP bodies, buyer data, or order data.

## Operate the executor

The console and users with the `gamecart.admin` permission can run `gamecart status`. It shows the plugin version, the Hytale release it supports, and whether it is connected. After you edit `config.properties`, run `gamecart reload` to apply it. Reloading never runs a command a second time.

Use one Hytale executor installation for each Gamecart server token.

If the executor can't reach Gamecart, it keeps retrying on its own and waits up to a minute between attempts. When Gamecart is reachable again, it reconnects without a reload. The console logs one line when the connection drops and another when it comes back.

If it keeps retrying with a `401` or `403` error, Gamecart is rejecting the server token. Check `serverToken` and `apiUrl` in `config.properties`, then run `gamecart reload`.

<Warning>
  If a command ran on your server but Gamecart never received the confirmation, resending it can deliver the purchase twice. Stop the original executor and check the outcome in the Gamecart dashboard before you resend.
</Warning>
