title: "Connect a server"

Start by creating the server integration that Gamecart will use for delivery.

## Before you begin

Make sure you have:

- A selected store in the dashboard.
- Permission to manage servers in that store.
- The target game server runtime identified.

## Create the connection

1. Open **Integrations > Servers** and click **Create Server**.
2. Under **Delivery method**, choose **Plugin**, **Script**, or **RCON**. The list only shows the methods your store's game supports.
3. Enter a **Name** you will recognize, such as `Survival`.
4. Click **Create server**.

## Copy the token

Plugin and Script servers use a connection token. The dashboard shows it right after you create the server, and it stays available in **Integrations > Servers**: click **Copy token** on the server's row whenever you configure the executor. RCON servers don't have a token.

Never include the token in screenshots, logs, repositories, or support messages.

<Frame caption="The list masks each token. Copy token copies the full value for that server.">

## Use one installation per token

Run only one executor installation for each server token. If two installations use the same token, either one can receive a command intended for the other runtime.

## Rotate safely

Before you rotate a token, stop the executor. Replace the token in its configuration, then reload or restart it.
