Pix is a Brazilian instant payment method. This page covers Pix through Mercado Pago. For Pix through Efí, see [Pix (Efí)](/tutorials/store-setup/payment-gateways/efi).

Pix only works on stores whose currency is BRL. Buyers pay on a Gamecart page that shows the QR code and the copy-and-paste code. You don't copy a webhook secret.

## Get the access token

1. Open [Mercado Pago Developers](https://www.mercadopago.com.br/developers).
2. Open the application you want Gamecart to use. The Mercado Pago account must be able to receive Pix.
3. Copy the **Access token**. Use the test token while you try the integration and the production token for real payments.

## Add it in Gamecart

1. Open **Settings > Gateways** and click **Add gateway**.
2. Click **Add** on **Pix**.
3. Set **Provider** to **Mercado Pago**.
4. Paste the token in **Access token**.
5. **Sandbox mode** starts on. Leave it on for a test token and turn it off for a production token.
6. Click **Save Configuration**.

7. Turn on the Pix switch in the gateway list when you are ready to take payments.

You can't switch this gateway to Efí while a Pix order is still pending with Mercado Pago.
