This gateway sends buyers to Mercado Pago Checkout Pro. It is separate from Pix: to take Pix through Mercado Pago, set up [Pix (Mercado Pago)](/tutorials/store-setup/payment-gateways/pix) as well.

Mercado Pago only works on stores whose currency is BRL. Gamecart only needs your access token, so you don't copy a webhook secret.

## Get the access token

1. Open [Mercado Pago Developers](https://www.mercadopago.com.br/developers).
2. Open the application you want Gamecart to use.
3. Copy the **Access token**. Use the test token while you try the integration and the production token for real payments.

## Add it in Gamecart

1. Open **Settings > Gateways** and click **Add gateway**.
2. Click **Add** on **Mercado Pago**.
3. Paste the token in **Access token**.
4. Turn on **Sandbox mode** only if the token is a test credential.
5. Click **Save Configuration**.

<Frame caption="Paste the access token. Sandbox mode is only for test credentials.">

6. Turn on the Mercado Pago switch in the gateway list when you are ready to take payments.

If a card payment is rejected in Checkout Pro, the order stays pending so the buyer can try again with the same checkout.
